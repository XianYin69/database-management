# 经验查询
动手前先查既往经验，避免重复踩坑。
## 检索顺序
1. **链经验**：`chain recall`（memory/knowledge/logic 三链）查同类数据任务结论与偏好。
2. **本地知识库**：grep [`references/`](../../../references/references.md) 的理论/建模/性能/演进摘要。
3. **既往工程**：同仓 `CHANGELOG.md`、`tests/`、历史迁移台账与提交（`git log --oneline`）。
4. **仍缺**：转 [浏览器学习](../浏览器学习/浏览器学习.md) 联网补齐，不得凭记忆臆造引擎行为。
## 动作
- 命中经验即引用其条目 id 写入逻辑链；无命中记 `--to 无既往经验`。
- 压缩上下文：`python -B scripts/context_compress.py --ratio 0.3 --kw <关键词>` 只留相关片段。
## 产出
- `logic_chain.jsonl` 经验条目 + 本次采用的方案候选清单（≥2 个，供分支分析取舍）。
