# 知识库构建
把本次任务所需的外部知识沉淀进 `references/`，拓扑至不可再出新领域为止。
## 动作
1. 选题：理论（关系模型/SQL 标准/ACID 与隔离）+ 书目（DDIA、高性能 MySQL、PG 文档）+
   建模（范式/反范式/多模型）+ 性能（索引/执行计划/连接池与锁）+ 演进（迁移/分片/备份 PITR）。
2. 抓取：`python -B scripts/knowledge_fetch.py --url <白名单页> --out tmp/downloads`
   （白名单：wikipedia / postgresql.org / dev.mysql.com / mongodb.com / apache.org /
   github / stackoverflow / *.org；须 `:grant network`）。
3. 转换：`knowledge_convert.py` 把 HTML 转 md 摘要，**只存摘要与出处，不存版权正文**。
4. 落库：`references/<领域>/<主题>.md`，每文件 ≤50 行，含来源标注：
   `[联网]` = 可溯 URL；`[本地]` = 模型既有常识未经联网确证（须先经浏览器学习确证再落实现）。
5. 拓扑判据：新主题能引出未覆盖的相邻领域 → 继续；引不出 → 收口并写明缺口归属。
## 产出
- [`references/references.md`](../../../references/references.md) 索引 + 各领域子目录。
## 兜底
- 网络不可用（如本次 urlopen 10060）：降级为 `[本地]` 标注 + 向用户说明缺口，禁止编造文献内容或伪造 URL。
- 缓存文件禁止写入 skill 目录（一律落用户缓存目录 / tmp）。
