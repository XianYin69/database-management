# 浏览器学习
横切强制节点：任一步遇到不明（引擎语法/版本行为、参数默认值、错误码、扩展插件）**必须**联网学习后再继续。
## 触发条件
- 需要的 SQL 语法、DDL 是否在线、参数默认值无法从本地资料确证。
- 报错信息（如 PG `40P01`/`62003`、MySQL `1213`/`1062`）不在已知模式内。
- 引擎小版本行为存疑（弃用、破坏性变更、复制与锁语义差异）。
- 涉及未用过的扩展/中间件（pgbouncer、Patroni、ProxySQL、Debezium 等）。
## 动作
1. 派 `file_ops` 技能（`local:skill_manage_system`）执行搜索/抓取：
   `python -B scripts/browser_learn.py --query "<问题>" --out tmp/learn`
   （内部走 ff_lite.py search/fetch，须 `:grant network`，未授权先申请）。
2. 取证：记录 URL、访问时间、**引擎与版本号**、关键结论；只取事实不抄正文。
3. 蒸馏：结论写入知识链（`chain append` knowledge 链）+ `references/<领域>/<主题>.md`，来源改标 `[联网]`。
4. 回原节点继续，并在逻辑链记「因 X 不明 → 学习 → 采用 Y」。
## 禁止
- 未学习即凭记忆写 SQL/解释报错/断言某版本行为。
- 学习结论不落链、不复用（重复浪费）。
- 无网络授权时伪造检索结果或编造 URL。
