# 范式与反范式建模（1NF→5NF 与读放大权衡）

来源：[本地]（未联网确证）· 用途：schema 设计评审判据。

## 范式阶梯

| 级别 | 要求 | 消除 |
|---|---|---|
| 1NF | 属性原子、无重复组 | 多值列（逗号串） |
| 2NF | 非主属性完全依赖主键 | 部分依赖（复合键下局部依赖） |
| 3NF | 非主属性不传递依赖主键 | 传递依赖（冗余派生列） |
| BCNF | 每个决定因素都是候选键 | 决定因素非键的异常 |
| 4NF | 无多值依赖冲突 | 独立多值关系混装 |
| 5NF | 无连接依赖可再分解 | 语义错误的拆分 |

- 异常类型：插入 / 更新 / 删除异常 = 范式要解决的三类问题。

## 反范式（有意为之）

- 手段：冗余列、物化视图、预聚合表、宽表、嵌套文档、反范式缓存列。
- 触发条件：读放大显著（热点聚合、跨表连接 >3）、报表/搜索场景、跨分片 join 不可用。
- 代价：更新放大、一致性窗口、需**同步机制**（触发器/应用双写/CDC）与校验任务。

## 判据

1. 默认 3NF/BCNF；反范式必须在大纲中写明「收益指标 + 同步方式 + 校验频率」，缺项即驳回。
2. 冗余列必须有唯一真源（source of truth）与派生规则，禁止两处各自可写。
3. 枚举/状态列优先用受约束类型（检查约束/引用字典表），避免裸字符串。
4. 主键选择：代理键 vs 业务键须留逻辑链；自然键变更风险 > 代理键成本时选代理键。
