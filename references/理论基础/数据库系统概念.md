# 数据库系统概念（Silberschatz / Korth「牛仔书」）

来源：[本地]（模型既有常识·本次环境外网不可达未联网确证）· 用途：原理基线。

## 核心框架

- **存储**：块/页、堆文件、排序文件、B+ 树、哈希索引、位图索引。
- **查询**：关系代数 → 逻辑计划 → 优化器（代价模型）→ 物理计划；连接算法 = 嵌套循环 / 排序归并 / 哈希连接。
- **事务**：ACID；调度可串行化；冲突可串行化判定 = 优先图无环；两阶段锁（2PL）与时间戳排序。
- **并发异常**：丢失更新、脏读、不可重复读、幻读；恢复 = WAL + ARIES（分析/重做/撤销）。
- **分布式**：CAP、2PC、共识（Paxos/Raft 概念层）、分片与复制。

## 对本技能的用法

1. 任何「为什么慢 / 为什么锁等待 / 为什么隔离级别不够」先回到本书概念定位，再查具体引擎文档。
2. 索引与执行计划术语以本书口径统一（聚簇 vs 辅助索引、覆盖索引、回表）。
3. 迁移/恢复流程的「先日志后数据」次序依据 = WAL/ARIES 原理。
